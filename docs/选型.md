# 当前选型

只记录现在接上的选择。依赖里有、运行路径没用的，放在文末。

## 形态

单体 Python 服务，一个进程。没有自研 Web 前端。人通过飞书或企业微信说话，HTTP 只提供 API。

## 前端 / 入口

| 用途 | 选型 |
|---|---|
| 需求对话 | 飞书。`lark-oapi` 长连接收消息和卡片；`POST /api/feishu/webhook` 为备用 HTTP 回调 |
| 老板问答 | 企业微信 CEO 应用。HTTP 回调，`httpx` 调接口，`pycryptodome` 解密 |
| 客服 | 企业微信客服应用。独立回调，Redis 队列削峰 |
| 浏览器页面 | 无。未使用 React / Vue / 静态站点，也未启用 CORS |

## 后端

| 用途 | 选型 |
|---|---|
| 语言 | Python |
| Web | FastAPI |
| 运行 | uvicorn，`0.0.0.0:8080`，单进程 |
| 配置 | pydantic-settings，读 `.env` |
| 数据模型 | pydantic v2 |
| HTTP 客户端 | httpx |
| 配置文件 | PyYAML |

## 数据

| 用途 | 选型 |
|---|---|
| 业务库 | PostgreSQL，`asyncpg` |
| 缓存 / 去重 / 客服队列 / 会话热数据 | Redis，`redis.asyncio` |
| 长期知识 | PostgreSQL + pgvector，表 `agent_knowledge` |
| 向量 | 阿里云百炼 `text-embedding-v4`，1024 维，`httpx` 调兼容接口 |

## 模型与执行

| 用途 | 选型 |
|---|---|
| Agent 对话 | DeepSeek。`httpx` 调 OpenAI 兼容接口，默认模型 `deepseek-v4-pro`，地址 `https://api.deepseek.com/v1` |
| 路由 | `LLMRouter` 所有角色都指向 DeepSeek |
| 写代码 | Claude Code CLI，子进程。外层强制 Docker，镜像 `muzhu-sandbox:latest` |
| 客户项目上线 | Docker 容器，或静态目录；宿主机 Nginx 反代（配置目录 `/etc/nginx`） |

## 协作方式

CEO 把需求拆成 DAG。`WorkflowExecutor` 按角色直接 `agent.run()`。角色是 CEO、Developer、FrontendExpert、DevOps、CustomerService。没有 Agent 之间的消息总线。

## 工程配套

| 用途 | 选型 |
|---|---|
| 接口限流 | SlowAPI |
| 指标 | prometheus-client，`GET /metrics` |
| 日志 | 标准 logging，JSON + trace_id |
| 健康检查 | `GET /health`，查 PostgreSQL、Redis、pgvector、Docker |
| 测试 | pytest，`asyncio_mode=auto`，覆盖率 pytest-cov |

## 依赖里有、当前没作为选型

`openai`、`anthropic` 两个 SDK 未使用，模型调用走 httpx。`ClaudeClient` 类在，路由器不创建它。`opentelemetry-api` / `opentelemetry-sdk` 未接入 exporter。
