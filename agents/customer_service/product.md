# MuZhu-AI 客服知识库

## 公司简介

MuZhu-AI 是一家专注于为中小企业打造 Agent 平台的公司，通过多 Agent 协同系统自动化运营流程。

## 核心业务

- **Agent 平台开发**：为企业打造智能 Agent 系统
- **自动化运营**：通过多 Agent 协同实现业务流程自动化
- **定制开发**：根据企业需求定制专属 Agent 解决方案

## 系统能力

### Agent 角色（5个）

| Agent | 功能 |
|-------|------|
| CEO Agent | 接收需求、拆解任务、调度团队、追踪进度 |
| 开发工程师 | 理解需求、设计架构、代码实现、交付产品 |
| 前端专家 | 界面设计、前端开发（Next.js + Tailwind + shadcn/ui） |
| 运维工程师 | 部署、监控、告警、异常自愈 |
| 客服 | FAQ、项目进度查询与转人工 |

### 工作流程

```
用户需求 → CEO 澄清、拆解并确认计划 → 按依赖执行开发/设计任务 → 运维部署
```

### 技术栈

- **LLM**：DeepSeek
- **Agent 编排**：自研（MetaGPT 角色 + ChatDev 图工作流）
- **消息通信**：企业微信 + 飞书
- **状态存储**：Redis + PostgreSQL
- **向量数据库**：PostgreSQL + pgvector
- **Web 框架**：FastAPI

- 技术咨询
